# LPU Campus Navigator

A C++ based campus navigation system that uses **Graph Algorithms and Dijkstra's Algorithm** to find the shortest route between LPU campus locations.

## Features

* Shortest path navigation
* Distance and estimated walking time
* Nearest facility search
* CSV-based campus data
* C++ GUI
* Dijkstra's shortest path algorithm

## Tech Stack

* C++
* CMake
* Graph Algorithms
* Dijkstra's Algorithm
* CSV

## Run

```bash
cmake -S . -B build
cmake --build build
.\build\campus_navigator_gui.exe
```
